Terrain generator · Object generator

Build Logic object generator

Describe something and an AI model designs it from boxes, beams, spheres and cylinders, and the page turns that into a save string. It works with a GitHub token (GitHub Models) or a Groq API key.

After a result, type a change (like "make the towers taller") and press Generate to refine it. Your key is passed through this site's server to the AI service and is not stored on the server. For GitHub, use a fine-grained token with the Models permission set to read.
